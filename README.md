# Kay Events & Inspirations

Today we are building an events application. The front page should have a search bar to choose the type of event one desires ,have a marquee tag from end to end stating book us today. If you choose  a wedding ,you are given realistic inspirations to chose from. Every inspiration will have a budget plan ,price and the duration it will take to set up. The event inspiration should  be downloadable for further  communication . Testimonials and star ratings for the services given. Enables the owner to add more inspiration to the website .Have contact or support for inquiries being email ,phone ,whatsapp ,instagram and tiktok. the theme should be magenta , some sage , burgundy ,rose gold ,mustard ,baby pink and some gold . Every event tab has a request for the event/ book event if interested ..name it kay events
